# Approve

一个浏览器里的放置类小游戏。实验室来了一个什么都不会的新模型，你从 10 以内的加减法开始教它：先自己做题，再让它补全，再审批它的答案。一局约 40 分钟。

纯 HTML + JavaScript，没有依赖，也不用构建。

## 运行

直接用浏览器打开 `index.html`，或者起一个静态服务器：

```sh
python3 -m http.server 4179
# 打开 http://127.0.0.1:4179/
```

存档自动保存在浏览器的 localStorage 里，关掉页面后 AI 也会继续做题（离线收益最多 8 小时）。重置存档在右下角的「设置」里。

## 开发

| 文件 | 内容 |
|---|---|
| `index.html` | 页面结构和全部样式 |
| `config.js` | 所有可调的数值和文案：题型、科技、目标、公投选项、新闻 |
| `core.js` | 游戏规则，不碰 DOM，浏览器和 Node 都能加载 |
| `ui.js` | 渲染、输入、存档、音效（WebAudio 现场合成）、特效 |
| `sim.js` | 节奏自检 |

### 节奏自检

改了数值或加了内容之后跑一遍：

```sh
node sim.js        # 默认 5 个随机种子
node sim.js 20 -v  # 20 个种子，打印详细过程
```

它会模拟熟练玩家和新手各打一局，打印每个里程碑的时间，节奏不达标时断言失败。

### 调试面板

在地址后面加 `?debug`（例如 `index.html?debug`），左下角会出现调试面板：加速 ×10 / ×100、加算力和数据、跳到指定阶段、导出各科技的购买时间。控制台里可以用 `dbg.s` 查看和修改当前存档。
